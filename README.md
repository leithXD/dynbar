A dynamic desktop shell for Hyprland built with Quickshell. It is very much a work in progress right now, but the goal is a shell that adapts dynamically to give you what you need at that moment. For example, the dynamic island switches to a miniplayer when media is playing, while the application launcher and wallpaper selector both morph out of the island.
